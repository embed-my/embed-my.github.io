# embed-my.github.io

Retired. This was the player origin of Embed My's snippets: the `/h5p` page each snippet framed,
`/h5p-resizer.js`, the sample packages and, for older copies of the h5p-author skill, `/bundles/`.
Embed My is now a hub for apps at [embed-my.org](https://embed-my.org/), in
[embed-my/website](https://github.com/embed-my/website).

What is left: `/h5p`, which a snippet still on a page frames, says that the player has retired; `/`
goes on to embed-my.org. The other old addresses are a 404.

The build page and the skill's bundles moved to Missing Elements' site: an old `/build#source=…`
link works at [missing-elements.github.io/h5p/build/](https://missing-elements.github.io/h5p/build/)
with the same `#source=`, and the bundles are under
[missing-elements.github.io/h5p/bundles/](https://missing-elements.github.io/h5p/bundles/).
